1 设计原则 (UX Principles) 6 principles
🎯

内容优先 · 3 秒抓重点

Hero KPI 占首屏 60% 视觉权重；次级数据以 chip / tag 方式弱化，保证每屏只有 1 个焦点。

👆

拇指友好 · 底部动作

CTA 放在下半屏；Bottom Sheet 取代弹窗；Bottom Nav 5 个 icon + 顶部 3px 高亮指示当前项。

⚡

即时反馈 · Motion Spec

Hover 120ms · Press 180ms · Page/Sheet 300ms；所有状态变化皆有 easing，避免硬切。

🌗

原生暗色 · 自动跟随

所有 token 内置 dark 映射 + prefers-color-scheme 自动切换；Surface 分层不丢失。

🧱

一致性 · 8pt 栅格

圆角 6/8/12/16/20/28；间距 4/8/12/16/20/24/32/40/48；阴影 xs~xl + 2 种 brand；不再出现"好看的特例"。

🌐

国际化 · 三语扩展

文本不硬编码；中/英/西 UI 同布局无错位；长文本有省略与 tooltip 兜底。

7 动效规范 (Motion Spec) NEW · prefers-reduced-motion 兼容

Hover · 悬停

--dur-fast 120ms --ease-out
H
按钮、卡片、链接上浮 ~ -1~-3px + 阴影升级

Press · 按压

--dur-base 180ms --ease-in-out
P
:active → scale(0.96~0.97)；避免"硬按"感

Enter · 进入

--dur-slow 300ms cubic-bezier(.16,1,.3,1)
E
页面路由 / 抽屉 / Toast / Bottom Sheet 入场

Page · 路由

--dur-slow 300ms fade + translateY(10px)
P
页面切换统一动画，避免白屏跳转

Easing curves · 缓动曲线

NameCurve场景
--ease-outcubic-bezier(.16, 1, .3, 1)所有用户触发的退出/释放（hover, release）
--ease-incubic-bezier(.4, 0, 1, 1)系统触发的消失（loading fade-out）
--ease-in-outcubic-bezier(.65, 0, .35, 1)对称状态切换（press, toggle）
