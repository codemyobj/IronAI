1 设计原则 (UX Principles)
🎯

内容优先

数据展示是核心，装饰为辅。每个页面让用户 3 秒内看到关键数据。

👆

拇指友好

底部 Tab 导航 + 底部弹出模态框，所有操作均在拇指可达区域内。

⚡

即时反馈

骨架屏加载、hover 微交互、进度环动画，让用户感知系统状态。

📱

移动原生

安全区域适配 (env safe-area)、100dvh 动态视口、PWA 主屏幕体验。

🔄

一致性

统一的圆角、阴影、间距和颜色系统，组件复用降低认知成本。

🌐

国际化

三语支持 (EN / 中 / ES)，文本不硬编码，布局适配长文本。

body_fat_pctFloat?体脂率 (%)
muscle_mass_kgFloat?肌肉量 (kg)
waist_cmFloat?腰围 (cm)
measured_atDate测量日期

9 交互流程 (UX Flow)

用户旅程: 记录训练

1. 📱 打开 App → Dashboard 首页
2. 👆 点击底部 Tab「训练」
3. 📋 浏览训练计划列表
4. ➕ 点击「+ New」按钮
5. ⬆️ 底部弹出模态框 (Bottom Sheet)
6. ✏️ 填写时长、强度等数据
7. ✅ 点击「Save Session」
8. 🔄 页面刷新，新记录显示
9. 📊 图表自动更新训练趋势

用户旅程: 记录饮食

1. 📱 打开 App → Dashboard 首页
2. 👆 点击底部 Tab「饮食」
3. 📅 选择日期 (默认今天)
4. 👀 查看当日宏量营养素概览
5. ➕ 在餐食组中添加食物
6. ⬆️ 底部弹出模态框
7. ✏️ 输入食物名称、卡路里、营养素
8. ✅ 保存后实时更新宏量数据
9. 📈 周趋势图同步更新

用户旅程: AI 分析

1. 📱 打开 App → Dashboard 首页
2. 👆 点击底部 Tab「AI」
3. 🤖 选择分析类型 (饮食/训练/目标)
4. ⏳ 显示 Loading Spinner
5. 🧠 DeepSeek AI 处理数据
6. 📝 返回 Markdown 格式分析报告
7. 📜 查看历史分析记录
8. 👆 可点击历史项重新查看
